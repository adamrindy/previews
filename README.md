# previews

Live previews of Adam Rindy's projects, published with GitHub Pages.

- Home: https://adamrindy.github.io/previews/
- Each project lives in its own folder with an `index.html`, e.g. `watanabe/` → https://adamrindy.github.io/previews/watanabe/

Every page includes `noindex` so it stays out of search engines, plus a "Preview" tag.
